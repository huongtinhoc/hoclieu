# Học liệu Tin học – Căn bản về công nghệ

Website học liệu cho học sinh THCS tự học tại nhà (Bài 1 → Bài 12).
Nội dung bài giảng giữ nguyên từ file PowerPoint gốc.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ: `hoc-lieu-tin-hoc`), chọn Public.
2. Bấm **Add file → Upload files**, kéo toàn bộ nội dung đã giải nén (index.html, lesson.html, style.css, common.js, data.js, thư mục slides, file .nojekyll) vào rồi **Commit**.
3. Vào **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, thư mục `/ (root)` → **Save**.
4. Sau 1–2 phút, trang có địa chỉ: `https://<tên-tài-khoản>.github.io/hoc-lieu-tin-hoc/`

## Thêm bài mới
Thêm ảnh slide vào `slides/<mã-bài>/01.webp, 02.webp…` và thêm một dòng vào `data.js`.
